# Changelog

## 0.1.0

Initial release.

- Sign in with a Personal Access Token stored in the OS keychain; multiple organizations; Azure DevOps Services and Server.
- Non-destructive verification of PAT scopes with a PAT Access page, sidebar summary and status bar indicator;
  locked features are marked throughout the UI and explain which scope to enable.
- Work items: personal lists, current iteration, saved queries, search, full editor, comments, links,
  quick actions, create (including from a code selection), branch creation, Markdown export for AI chat.
- Pull requests: lists, file diffs with inline review comments, review page with votes, checks, threads,
  completion and auto-complete, create pull request from the current branch, branch checkout.
- Pipelines: pending approvals, recent and personal runs, pipelines by folder, classic releases, stage/job/task
  timelines, live syntax-highlighted logs, run/re-run/cancel/retry.
- Repos: clone, open file in Azure Repos, copy link to selection.
